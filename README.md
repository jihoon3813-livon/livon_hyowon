# 리본케어 × 효원상조 랜딩페이지

안티그래비티에서 기존 디자인을 이어서 수정하기 위한 소스와 작업 지침입니다.

## 시작하기

1. ZIP 파일을 압축 해제합니다.
2. `index.html`, `style.css`, `app.js`가 들어 있는 `reborn-hyowon-landing` 폴더를 안티그래비티의 프로젝트 폴더로 엽니다. 버전에 따라 Add Folder 또는 Open Folder를 사용합니다.
3. `START_PROMPT.txt` 내용을 대화창에 붙여넣습니다. 지침 파일의 자동 인식 여부와 관계없이 명시적으로 읽도록 요청하는 방식입니다.
4. 빠른 확인은 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드 없이 동작합니다.
5. HTTP 실행이 필요하면 아래 방법을 사용합니다.

### 로컬 서버

Python 3이 설치되어 있을 때 프로젝트 폴더의 터미널에서 실행합니다.

Windows:
```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS 또는 Linux:
```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

접속: http://127.0.0.1:8000/
종료: 서버를 실행한 터미널에서 Ctrl+C.
Python이 없다면 우선 HTML 파일을 직접 열거나, 안티그래비티에서 사용 가능한 로컬 서버로 실행하도록 요청하세요. Node.js와 npm 설치는 사이트 자체의 필수 요건이 아닙니다.

## 현재 상태

- 정적 HTML/CSS/JavaScript 사이트입니다. 프레임워크, 데이터베이스, 서버 API가 없습니다.
- 모바일 반응형 레이아웃, 이용금액 계산기, 상품 선택 연동, 펼침형 FAQ가 구현되어 있습니다.
- 상담폼은 데모입니다. 제출 시 전송하지 않고 입력값을 초기화한 후 예시 완료 메시지를 표시합니다.
- Google Fonts에서 글꼴을 불러옵니다. 따라서 완전한 오프라인 전용 구성은 아닙니다. 폰트 로딩이 차단되면 시스템 sans-serif로 표시됩니다.
- 상품 조건은 제휴 제안 상태이며 실제 판매 확정 조건이 아닙니다.
- 브라우저 화면 검증은 미완료 상태입니다. 모바일·PC 화면 확인은 QA 체크리스트를 따라 진행하세요.

## 원본과 배포

참고 사이트: https://reborn-hyowon-family-care.hoony365.chatgpt.site

이 패키지는 해당 사이트의 게시 버전 1 소스에서 만든 독립 복사본입니다. ChatGPT 로그인이나 호스팅 토큰 없이 로컬에서 수정할 수 있습니다. 로컬 수정이 원래 사이트에 자동 반영되지는 않습니다.

별도 호스팅 시 공개 웹 파일은 `index.html`, `style.css`, `app.js`, `assets/`입니다. 작업 지침·검토 기록은 공개 배포 대상에서 제외하세요. 기존 사이트를 수정하려면 변경 파일을 다시 전달하여 반영하거나 사용자가 지정한 배포 경로를 사용합니다.
