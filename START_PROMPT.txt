이 폴더는 리본케어 × 효원상조 간병상품 랜딩페이지 소스야.

먼저 README.md, GEMINI.md와 docs 폴더의 문서를 읽고 index.html, style.css, app.js를 확인해줘.
현재 디자인과 기능을 유지한 상태에서 로컬로 실행하고, PC 1440px와 모바일 390px·360px 화면을 확인해줘. 이미지와 폰트, 하단 고정 상담 버튼, 상품 선택 연동, FAQ, 이용금액 계산기가 정상인지 살펴봐.

확인 과정에서 발견되는 깨진 화면이나 기능 오류는 수정해줘. 전면 재설계나 프레임워크 변경은 하지 말고, 상품 금액·납입기간·간병일수·환급 조건은 유지해줘.

상담폼은 디자인 시안이야. 실제 접수 연동을 별도로 요청하기 전까지 개인정보를 저장하거나 전송하지 마. 제품 제안 조건을 실제 확정된 서비스로 바꾸지 마.

완료 후 실행 주소, 수정한 파일, 확인 결과와 남은 작업을 알려줘. 브라우저 접근이 불가능하면 확인하지 못한 부분을 구분해줘. 이후 내가 요청하는 디자인이나 기능 변경을 이어서 진행하자.
