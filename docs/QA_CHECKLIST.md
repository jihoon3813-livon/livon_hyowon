# 확인 항목

## 패키징 시 확인한 범위

원본 게시 버전 1과 로컬 커밋이 일치하며 작업 파일에 변경이 없음을 확인했다. 웹 파일은 내용 변경 없이 복사했다. ZIP 무결성, 원본과의 바이트 일치, JS 문법, 주요 계산 5개 사례와 내부 링크 대상을 확인했다.

브라우저 렌더링, 실제 모바일 터치와 폼 브라우저 검증은 이번 인계 시 수행하지 않았다. 아래 항목을 안티그래비티 환경에서 확인한다.

## 화면

- 1440px, 768px, 390px, 360px 너비에서 가로 스크롤·잘림이 없는가.
- 히어로 이미지의 인물과 제목이 적절하게 보이는가.
- 월 납입액·총액·기간·간병 이용조건을 함께 읽을 수 있는가.
- 상품표의 긴 서비스명이 깨지거나 겹치지 않는가.
- 하단 고정 상담 버튼이 폼 입력과 완료 메시지를 가리지 않는가.
- 폰트 로딩 실패 시에도 내용을 읽을 수 있는가.

## 동작

- 내비게이션과 CTA가 올바른 섹션으로 이동하는가.
- 240·450 상품 상담 버튼이 관심 상품 선택값에 반영되는가.
- PRODUCT_RULES.md의 계산 5개 사례가 일치하는가.
- 450형의 납입개월 300을 입력한 뒤 240형으로 바꾸면 160 이하로 제한되는가.
- 음수·빈 입력·소수·상한 초과 납입개월을 입력한 결과가 음수·NaN으로 표시되지 않는가.
- FAQ를 키보드와 터치로 열고 닫을 수 있는가.
- 상담 필수항목을 비워 두면 완료로 진행하지 않는가.
- 폼 제출 후 정보가 초기화되고 '실제 신청 미전송' 안내를 확인할 수 있는가.
- 브라우저 네트워크에서 폼 값이 외부로 전송되지 않는가. 외부 폰트 다운로드와 폼 전송을 구분한다.

## 실판매 전 결정할 사항

상품·환급 약관, 상담 주체·시간·전화번호, 개인정보 처리 내용, 인력 배정과 교체 기준을 확정한다. 승인된 로고와 사용권이 확보된 이미지를 적용한다. 실제 접수 기능을 구현한 경우 성공·실패·중복 제출을 확인한 뒤 데모 표시를 수정한다.
