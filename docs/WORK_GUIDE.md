# 안티그래비티 작업 지침서

## 1. 목적과 페이지 흐름

부모님 간병을 걱정하는 고객이 가족 이용 방식과 납입 조건을 이해하고 상담을 신청하도록 설계했다. 240형을 주력으로 안내하고 450형을 비교 선택지로 제시한다.

현재 순서: 첫 화면 → 간병 고민 → 핵심 혜택 → 가족 사용 예시 → 이용금액 계산기 → 신청·배정 과정 → 간병인·보호자 관리 → 상품 비교·환급 → FAQ → 상담 신청.

## 2. 기술 구성

정적 파일 세 개와 이미지 하나로 동작한다. 빌드, 패키지 설치, 서버 API가 필요 없다. `index.html` 하단에서 `app.js`를 로드하므로 DOM 생성 후 실행된다. CSS에는 Google Fonts의 Noto Sans KR 외부 요청이 있다.

## 3. 디자인 기준

| 항목 | 기준 |
|---|---|
| 기본 배경 | `--cream: #faf9f3` |
| 주요 텍스트 | `--ink: #193e34` |
| 버튼 | `--green: #285849` |
| 계산 결과 강조 | `--lime: #dce8b5` |
| 소제목 강조 | `--orange: #bd663e` |
| 최대 본문 너비 | 1160px |
| 반응형 구간 | 950px 이하, 640px 이하 |

큰 한글 제목, 짧은 설명, 여백을 중심으로 유지한다. 모바일 첫 화면에는 월 납입액·총액·기간이 함께 보여야 한다. 고정 하단 CTA와 본문이 겹치지 않도록 하단 여백을 유지한다.

## 5. 주요 인터랙션

- 상품 비교의 상담 버튼: `data-plan` 값으로 `#interest`를 선택하고 상담 영역으로 이동한다.
- 계산기: 상품에 따라 간병일수 선택 범위와 납입개월 상한이 변경된다.
- FAQ: HTML `details/summary`로 동작한다.
- 상담폼: 브라우저 필수항목 검증 후 `preventDefault()`로 전송을 차단한다. 폼 초기화 후 데모 완료 메시지를 표시한다.

## 6. 현재 계산기의 범위

이전 서비스 이용·추가 납부가 없는 월 15,000원 기본 납입 사례만 계산한다. 신청 일수는 2일부터 상품 최대 일수까지 선택한다. 마지막 잔여 1일 사용은 상품 설명에 포함되지만 이전 사용 이력이 없는 현재 계산기의 선택 대상에는 포함되지 않는다.

상담용 정식 계산기로 확장할 때에는 누적 실제 납입액·누적 사용 차감액·잔여 일수·특수 차액·납입 단축형 입력을 별도 설계한다. 현재 화면을 모든 계약 사례에 적용 가능한 계산기로 표현하지 않는다.

## 7. 실제 상담 접수 연동을 요청받았을 때

고객이 지정한 저장소·CRM·알림 수신처와 개인정보 수집 주체·이용 목적·보유기간·동의 문구를 확정한다. 임의의 개인 메일이나 외부 데이터베이스로 전송하지 않는다.

프런트엔드 검증과 서버 검증, 전송 중 버튼 상태, 중복 제출 방지, 실패 재시도 안내를 구현한다. 성공 응답을 받은 경우만 접수 완료를 표시한다. 실제 전송 기능을 적용한 뒤 데모 문구를 함께 수정한다. 민감한 환자 정보는 초기 상품 상담폼에 추가하지 않는다.

## 8. 배포와 원본 반영

로컬 편집은 원본 사이트에 자동 반영되지 않는다. 별도 정적 호스팅에는 웹 파일만 업로드한다. 사용자 계정의 배포 대상이 확정되기 전에는 공개 배포하지 않는다. 기존 ChatGPT 사이트 반영이 필요하면 수정된 웹 파일과 변경사항을 전달한다.
